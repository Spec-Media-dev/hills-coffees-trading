The marketplace offer card — origin eyebrow, lot name in Benito, spec grid, price row.

```jsx
<ListingCard title="Yirgacheffe Kochere Lot 14" origin="Ethiopia" region="Yirgacheffe"
  grade="G1" process="Washed" harvest="2025/26" quantity="320 bags · 60kg"
  price="USD 4.80 / kg" seller="verified" sellerName="Abyssinia Exports" onOpen={open} />
```

The ownership badge (`seller`) is required — Hills lots read cream, verified-seller lots read forest.
Guests get `priceLocked`. No photography was supplied with the brand kit, so the media area falls back to a labelled placeholder.
