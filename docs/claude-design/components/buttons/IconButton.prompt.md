Square icon-only control for toolbars, table rows, topbars and dark chrome.

```jsx
<IconButton icon={<Icon name="sun" size={18} />} label="Switch to light" variant="onDark" />
<IconButton icon={<Icon name="more-horizontal" size={18} />} label="Row actions" variant="ghost" size="sm" />
```

`label` is mandatory. Use `onDark` inside the forest sidebar/topbar. `md` (44px) keeps the touch minimum.
